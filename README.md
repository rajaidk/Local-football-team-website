# Local Football Team Website

A multi-page website for a local football club, built as a Semester 1 group project for **Internet Application** at [Asia Pacific University].

🔗 **Live site:** [View the website](https://rajaidk.github.io/Local-football-team-website/IAPP/home.html)

## About the Project
This website lets visitors explore the club, view upcoming events and news, register for classes, and send feedback. The goal was to design a responsive, easy-to-navigate site using core front-end web technologies.

## Features
- Home, About, News, Events, Gallery, and Contact pages
- Classes and equipment information pages
- Registration and feedback forms
- Dark mode toggle
- Interactive JavaScript mini-games
- Wireframes planned before development

## Built With
- **HTML5**: page structure
- **CSS3**: styling and layout
- **JavaScript**: interactivity (dark mode, games)
- **GitHub Pages**: hosting
